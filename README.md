## Como rodar (web - porta 8080)

Para abrir a aplicação web sempre na porta `8080`, use o script abaixo:

```bash
./scripts/run_web_8080.sh
```

Ou execute manualmente:

```bash
flutter run -d web-server --web-hostname=127.0.0.1 --web-port=8080
```
